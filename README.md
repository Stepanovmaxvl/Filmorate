# Filmorate

Веб-приложение для работы с фильмами и пользователями.

## Схема базы данных
ER-диаграмма лежит в корне Filmorate\Schema.png, рядом с README.md
Ниже текстовое описание

## Описание таблиц


### Справочные таблицы

**mpa_ratings** - рейтинги MPA
- `id` - идентификатор (PK)
- `code` - код рейтинга (G, PG, PG-13, R, NC-17)
- `description` - описание рейтинга

**genres** - жанры фильмов
- `id` - идентификатор (PK)
- `name` - название жанра

### Основные таблицы

**users** - пользователи
- `id` - идентификатор (PK)
- `email` - электронная почта (уникальное)
- `login` - логин (уникальное)
- `name` - имя пользователя
- `birthday` - дата рождения

**films** - фильмы
- `id` - идентификатор (PK)
- `name` - название фильма
- `description` - описание (максимум 200 символов)
- `release_date` - дата выпуска
- `duration` - продолжительность в минутах
- `mpa_rating_id` - ссылка на рейтинг MPA (FK)

### Таблицы связей

**film_genres** - связь фильмов и жанров (многие-ко-многим)
- `film_id` - идентификатор фильма (FK)
- `genre_id` - идентификатор жанра (FK)
- Составной первичный ключ (film_id, genre_id)

**likes** - лайки пользователей фильмам
- `film_id` - идентификатор фильма (FK)
- `user_id` - идентификатор пользователя (FK)
- Составной первичный ключ (film_id, user_id)

**friendships** - дружба между пользователями
- `user_id` - идентификатор пользователя (FK)
- `friend_id` - идентификатор друга (FK)
- `status` - статус дружбы (UNCONFIRMED - неподтверждённая, CONFIRMED - подтверждённая)
- Составной первичный ключ (user_id, friend_id)
- Ограничение: user_id != friend_id
